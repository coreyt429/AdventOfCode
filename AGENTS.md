# Agent Instructions

This repository is a personal Advent of Code practice space. Its primary purpose
is for the repository owner to develop and test their own puzzle-solving skills.

## Default behavior

- Do not create, modify, or complete code unless the user explicitly asks for
  code changes.
- Treat requests to explain, inspect, review, debug, or discuss code as
  read-only unless the user clearly requests an implementation or edit.
- Do not proactively fix issues, fill in TODOs, refactor code, or add features.

## Puzzle solutions

- Puzzle solutions belong to the user. Do not implement, complete, or reveal a
  solution to an Advent of Code puzzle unless the user explicitly asks for that
  specific help.
- Prefer hints, questions, explanations, and feedback that preserve the user's
  opportunity to solve the puzzle themselves.
- When the requested level of help is ambiguous, stop short of solution code and
  ask before disclosing or implementing more.

## Automation and testing

- The user may ask for help with repository tooling, automation, test harnesses,
  utilities, and similar support code. Implement these only when explicitly
  requested.
- Keep support-code changes separate from puzzle-solving logic. Do not use a
  tooling or testing request as permission to implement the puzzle solution.
